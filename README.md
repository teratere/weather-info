# 🌤️ TenkiHub - 気象庁オープンデータ天気予報

気象庁公式のオープンデータ（Web表示用公開JSON）を直接参照して描画する、完全ブラウザ完結型・登録不要・APIキー不要のお天気ダッシュボードです。

全国47都道府県およびその配下の主要一次細分区を選択でき、6時間ごとの降水確率推移（自作インラインSVG・日付境界破線付き）や向こう7日間の週間天気予報を直感的に確認できます。

🔗 **Webデプロイ先 (Live Demo):**  
https://selfup.net/weather/

---

## 🌟 主な機能 (Features)

### 1. 2階建て地域セレクター
- **都道府県 ➔ 主要エリアの階層選択:** 全国47都道府県の一覧から、各都道府県内の詳細な予報区（例: 東京地方、伊豆諸島、小笠原諸島など）を絞り込み選択
- **GPS現在地判定:** 端末の位置情報から最も近い予報区および観測エリアを自動判定
- **選択状態の自動保持:** 最後に閲覧した地域はブラウザの `localStorage` に自動保存

### 2. 直感的なお天気ダッシュボード
- **今日の天気カード:** 天気アイコン、テロップ、風向、予想最高/最低気温、おでかけ目安（傘の必要判定）
- **降水確率バー (自作インラインSVG):** 6時間ブロックごとの降水確率推移を可視化。「今日」「明日」の日付境界線を破線でわかりやすく区分表示
- **週間天気予報:** 向こう7日間の天気、予想気温、降水確率、予報信頼度をグリッド表示
- **気象概況解説:** 折りたたみアコーディオンで気象庁公式の解説テキストを閲覧可能

### 3. 軽量・安全な設計
- **完全単一HTML (Single File):** 外部JSライブラリ（Chart.js等）を一切使わず、Vanilla JavaScript とインラインSVGのみで高速描画
- **通信負荷の軽減 (30分キャッシュ):** 気象庁の公的サーバーへの過剰なアクセスを防ぐため、一度取得したデータはブラウザ内に30分間ローカルキャッシュ
- **ダークモード対応:** 画面右上のアイコンからワンタップでライト/ダークテーマの切り替えが可能
